# Анализатор логов ADS‑B и Mode S

## Описание

Программа для парсинга, глубокого анализа и визуализации авиационных логов (форматы ADS‑B и Mode S).  
Скрипт автоматически распознаёт сообщения, извлекает параметры целостности (NIC, SIL) и точности (NACp, NACv, GVA), переводит их в физические величины (HIL, HFOM, VFOM), выявляет аномалии (спуфинг, джамминг) и запускает интерактивный веб‑дашборд для исследования полётных данных.

---

## Функциональность

### 1. Парсинг и сводная таблица в консоли

При запуске `main.py` программа обрабатывает лог-файл (автоматически ищет в папке `data` или принимает путь через аргументы).  
В консоль выводится таблица с колонками:

- **ICAO** — 24‑битный адрес самолёта.
- **Рейс/SQ** — позывной (Callsign) или код ответчика (Squawk).
- **Формат** — перечень обнаруженных Downlink Formats (DF11, DF17, DF20 и т.д.).
- **Первое / Последнее (UTC)** — временные метки с точностью до наносекунд.
- **Флаги данных** (наличие `+` или `-`):  
  `POS` – координаты, `HDG` – курс, `SEL` – выбранная высота, `DIF` – разница высот, `BAR` – барокоррекция, `GNS` – GNSS‑высота, `NB` – флаг целостности барометрической высоты.

*Борта, не передающие ADS‑B координаты (DF17/DF18), отфильтровываются из таблицы и графиков, но учитываются в общей статистике.*

### 2. Детектор аномалий (спуфинг / джамминг)

Модуль `utils.py` содержит класс `AnomalyDetector`, который анализирует:

- резкие скачки скорости, курса, высоты;
- низкие значения целостности (NIC);
- расхождение заявленной скорости и скорости по координатам;
- пропуски координатных сообщений (DF17/18) при наличии других пакетов;
- временны́е дрейфы (TOA);
- несоответствие разницы высот с учётом барокоррекции (QNH) – признак спуфинга высоты.

Обнаруженные аномалии отображаются в **журнале безопасности** веб‑интерфейса и выделяются красными вертикальными областями на графиках.

### 3. Графический веб‑интерфейс (Dash + Plotly)

После обработки данных автоматически запускается локальный сервер.  
Откройте в браузере адрес: **http://127.0.0.1:8050**

#### Управление

- **Выбор борта** – выпадающий список (отображается позывной, ICAO, активные режимы автопилота).
- **Статус‑бейдж** – показывает общую оценку стабильности сигнала (норма / критическая аномалия).
- **Выбор режима визуализации** – переключатель типов графиков.
- **Включение реальной карты (Mapbox)** – для режимов треков (требует доступа к open‑street‑map).

#### Доступные режимы графиков

| Режим | Описание |
|-------|----------|
| **Схема трека (2D карта)** | Все треки на одной карте. Сегменты с аномалиями выделены красным. |
| **Трек борта с качеством NIC** | Трек выбранного борта, цвет линии соответствует значению NIC (зелёный – высокое качество, красный – низкое или аномалия). |
| **Кинематика (высота, скорость, курс)** | Три графика: барометрическая/GNSS/выбранная высота, путевая скорость, курс. |
| **Категории целостности и точности** | NIC, SIL, NACp, GVA, NACv в кодовых значениях. |
| **Физические метрики (HIL, HFOM, VFOM)** | Перевод категорий в метры: горизонтальный предел целостности, горизонтальная и вертикальная точность. |
| **Барометрический анализ** | Разница высот (GNSS – Baro) с порогами ±500 фт и барокоррекция (QNH). |
| **Качество данных в %** | Интегральные проценты (0–100%) для HIL, HFOM, VFOM – наглядная оценка стабильности сигнала. |
| **Спуфинг‑анализ: кинематика** | Сравнение заявленной путевой скорости и скорости, рассчитанной по координатам. |
| **Джамминг‑анализ: активность пакетов DF** | Распределение типов сообщений (DF) по времени, цветные маркеры. |
| **Интенсивность сообщений** | Частота всех сообщений и отдельно координатных (DF17/18) – резкое падение последних при сохранении общей активности указывает на подавление GNSS. |

#### Таблицы (внизу страницы)

- **Сводная информация по всем бортам** – ICAO, позывной, последние высота/скорость, статус. Доступен экспорт в Excel (кнопка "Скачать таблицу (XLSX)").
- **Журнал безопасности** – список обнаруженных аномалий с указанием временного интервала, типа (спуфинг, подавление, мультифакторная) и описания.  
  *Клик по строке автоматически масштабирует график к этому интервалу.*

## Требования и установка

### Системные требования

- **Python:** версия **3.10** или выше.
- **Операционная система:** Linux (Ubuntu/Debian/Mint), Windows 10/11.

### Установка для Linux (Ubuntu / Debian / Mint)

1. Установите системные зависимости:
    ```bash
    sudo apt update
    sudo apt install python3 python3-pip python3-venv python3-tk
    ```
2. Создайте и активируйте виртуальное окружение (рекомендуется):
    ```bash
    python3 -m venv venv
    source venv/bin/activate
3. Установите библиотеки Python:
    ```bash
    pip install numpy pandas pyModeS dash plotly openpyxl

### Установка для Windows
1. Убедитесь, что установлен Python 3.10+.

2. Откройте терминал (CMD или PowerShell) и выполните:
    ```bash
    pip install numpy pandas pyModeS dash plotly openpyxl
    ```
### Как использовать
1. Структура папок
Все файлы программы (main.py, decoder.py, visual.py, utils.py, models.py, config.py) должны находиться в одной директории.

2. Подготовка данных
Создайте папку data рядом с main.py и поместите туда лог‑файлы (расширение .t4433, настраивается в config.py).

3. Запуск программы

    - Автоматический режим (берётся первый файл .t4433 из data/):
        ```bash
        python main.py
        ```
    - Указание конкретного файла:
        ```bash
        python main.py -f "путь/к/файлу.t4433"
        ```
    - Фильтрация по одному борту (ICAO) – загружается файл, но графики и сводка строятся только для указанного hex‑адреса:
        ```bash
        python main.py -a 4249F5
        ```
4. Работа с веб‑интерфейсом
После запуска в консоли появится сообщение:
    ```bash
    запуск веб-интерфейса. откройте в браузере: http://127.0.0.1:8050
    ```
    Перейдите по ссылке, используйте выпадающие списки и переключатели.
